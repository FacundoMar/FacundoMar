## ¡Hola! Soy Facundo Martín

🎓 Soy estudiante avanzado de Ingeniería Informática en la Universidad Argentina de la Empresa (UADE), con interés en el desarrollo de software, las bases de datos y la seguridad informática.

💻 A lo largo de mi formación académica participé en distintos proyectos, tanto individuales como grupales, que me permitieron adquirir experiencia práctica en el desarrollo de aplicaciones web y móviles, diseño e implementación de APIs REST, gestión de bases de datos y trabajo colaborativo utilizando Git y GitHub.

🚀 Me interesa seguir profundizando mis conocimientos, incorporar nuevas tecnologías y enfrentar desafíos que me permitan crecer profesionalmente. Actualmente, busco oportunidades de pasantías o posiciones trainee en el área de IT, donde pueda aplicar lo aprendido y continuar desarrollando mis habilidades.

🛠️ Tecnologías y herramientas

Lenguajes: Python, Java, JavaScript y SQL.

Backend: FastAPI, Spring Boot y APIs REST.

Frontend: React, HTML y CSS.

Bases de datos: PostgreSQL, MySQL, MongoDB, Redis y Cassandra.

Herramientas: Git, GitHub y Docker.
